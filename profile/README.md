# Cordis Labs

核心研究：论文的独立实现，每篇带一个能对照的判据。

标准不在数量，在能不能对上。每个切片都要有一个**不依赖训练**的正确性来源——解析解、精确等价、
小规模暴力枚举，或者有限差分梯度校验——外加一份说明「论文报告 / 本仓实测 / 差异归因」的 README。
